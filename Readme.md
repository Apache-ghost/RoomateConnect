# RoomMate – A Cloud-Based Roommate Discovery and Matching Platform

**RoomMate** is a comprehensive, cloud-based web platform designed to help individuals across communities find compatible roommates easily and securely. The platform leverages modern web technologies to provide a **scalable, fault-tolerant, and collaborative environment** for people seeking shared accommodation based on location, budget, lifestyle preferences, and personal interests.

## Project Overview

EduComplain allows students to submit complaints about academic or administrative issues via a **mobile-friendly web interface**. Administrators or school officials can view, prioritize, and respond to complaints on a centralized dashboard. The system ensures timely resolution, transparency, and accountability while maintaining student anonymity if needed.

---

## Core Features

### Complaint Submission Form
Students can submit complaints with:

- Complaint category (academic, administrative, facilities, etc.)
- Description of the issue
- Optional file attachment (photo, document)
- Student ID / contact (optional for anonymous submissions)

### Dashboard for Officials
Administrators can:

- View all complaints with status filters (pending, in-progress, resolved)
- Assign complaints to specific staff or departments
- Add comments, notes, and mark complaints as resolved
- Track response times and complaint history

### Notifications (Optional)

- Email or SMS notifications to students when complaints are updated or resolved
- Alerts to staff for newly submitted or high-priority complaints

### User Roles

- **Student / Reporter:** submit complaints, view personal complaint status
- **Staff / Technician / Reviewer:** handle assigned complaints, update status
- **Admin:** full control, assign complaints, manage users, and generate reports

---

## Why This Solves a Problem in Africa

- Many schools and universities struggle to **track complaints efficiently**, leading to delays or unresolved issues.
- A centralized, cloud-based system **reduces manual paperwork**, prevents lost complaints, and ensures accountability.
- Supports **low-bandwidth mobile browsers** and simple file uploads, making it accessible in rural or resource-constrained regions.
- Encourages **transparency and collaboration** between students, staff, and school management.

---

## Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MySQL
- **File Storage:** Local storage or cloud storage (S3/GCS/Azure Blob) for attachments
- **Authentication & Authorization:** JWT / Role-based access control
- **Notifications (optional):** Email / SMS via external API or local gateway

---

## Benefits

- Streamlines student complaint management in schools and universities
- Increases student satisfaction by enabling fast, transparent responses
- Reduces manual administrative work and paper usage
- Provides a **cloud-ready architecture** that can scale across multiple institutions
